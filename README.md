# compass-seo-dashboard (retired)

This dashboard moved into **Compass Hub** (`adamsahli03/compass-cv-db`, section SEO) on 20 October 2026.
The daily Search Console / GA4 refresh now runs there, behind a staff login, and its data and keyword
list are no longer published here. The workflows in this repo are disabled.

To finish retiring it, the repo owner (admin) should: Settings → Pages → unpublish the site, then
Settings → General → Danger Zone → change visibility to Private (or archive the repo), and remove the
`analysis` DNS record for compass-arabia.com.
